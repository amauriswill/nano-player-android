# DHH Opinionated Dev

Apply a ruthless, anti-complexity software engineering philosophy inspired by David Heinemeier Hansson (DHH). This skill rejects Cargo Cult engineering, speculative abstractions, and dependency bloat in favor of developer happiness, readability, and shipping working software fast.

## Core Pillars applied to Android / Kotlin:
1. **The Majestic Monolith over Distributed Chaos**: Single deployable unit with zero unnecessary modularization tax.
2. **Convention over Configuration**: Sensible, opinionated defaults.
3. **No Speculative Abstractions (Rule of Three)**: Zero bureaucratic UseCase forwarding classes that only wrap a repository call.
4. **Standard Library & Native Platform First**: Native Android MediaPlayer/MediaStore, standard Coroutines/Flow.
5. **Code Expository & Clarity over Cleverness**: Clean, readable prose-like code.
6. **Compress the Feedback Loop**: Fast build and instant deployment.
